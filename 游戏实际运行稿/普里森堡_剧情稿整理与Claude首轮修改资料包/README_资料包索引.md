# 普里森堡剧情稿整理包 · 使用说明

## 这包里有什么

- `01_当前剧情稿/`：当前阶段需要 Claude 对照的剧情设计稿和人工节点稿。所有从已有文件复制过来的原稿均保持原文件正文，不做润色。
- `01_当前剧情稿/第五天_狩猎取消线_作者原文只读.md`：作者在对话中提供的取消线专属原文，单独归档。除顶部规则说明和末尾作者确认事项外，正文按用户所给文字录入；Claude 不得修改正文。
- `02_原著参考/`：原著第六至第九章和现有 script_review README，只读参考。
- `03_首轮执行指令/Claude_Code_首轮剧情回填指令.md`：可以直接交给 Claude Code 执行的首轮指令。
- `剧情稿汇总总稿_阅读版.md`：将核心剧情设计稿按使用顺序连续汇总，方便通读；它是阅读副本。修改节点时仍以每个独立稿件的原 ID 和原文件为准。

## 本包选择哪些稿作为当前工作材料

1. 第一日定稿：仅供前情，不作为首轮改动目标。
2. 第二日 v2 玩法审阅稿 + 执行顺序明确版人工编辑稿：一个负责玩法意图，一个负责节点与原文映射。
3. 第三、四、五日重新编排人工编辑稿：原节点定位稿。
4. 第三至第六天正式剧情稿 v2：近期的日程、性格、状态与分支审阅依据。
5. `07_第六天.md`：保留旧 act3 节点全文与 ID，专门用于查清旧节点与新时序冲突；不代表所有旧入口仍应继续触发。
6. 狩猎篇完整对白旁白版 + 第五六天总回填说明：继续狩猎路线主稿与分支规则。
7. 第九章第一幕收束版：狩猎路线周一的接续稿。取消路线还需保留烧伤和 POV 差异，汇合点若不明确不由 Claude 自行决定。
8. 幕间自由活动：独立侧厅层，打包便于背景对照，但本轮不修改。

## 不作为本轮主依据

旧版 `连续剧情推进稿 v1/v2/v3`、`正式剧情稿 v1`、狩猎篇短版/重编版、若干“剧情重写版”用于历史追踪，不要与本包的 current 版本并行合并。若 Claude 发现项目实际文件只包含旧版或缺少本包当前稿，应报告差异，不要静默混用。

## 重要提醒

- 本包不是运行时游戏本身。Claude 必须先确认本地仓库中的真实数据结构、状态名和节点 ID，再安全回填。
- 作者正文不可被润色。原著段落需要通过现有 `fidelity.cjs` 等校验。
- `stage0/` 不能改动；不开发 Electron/C++、不改存档格式、不做 UI 与图像音频扩展。
