# 狩猎篇 + 第五、六天 · 总回填说明

## 一、最终时间线

- Day 5：周五。第五天夜晚做“是否继续周日狩猎”的世界决定。
- Day 6：周六。照常上课、午饭、洗衣；若狩猎继续，周六再由布朗向西比拉正式通知，并送达骑装。
- Day 7：周日。
  - `huntDecision=1`：狩猎篇，西比拉视角，第四～第八章。
  - `huntDecision=2`：普通休息日，上午休息，午后祭拜日固定事件。
- 狩猎篇结束：`h8_end`。
- `h8_end` 不弹“第一幕尾声”提示。
- 下一节点直接进入第九章；第九章继续西比拉视角。
- 第九章结束后第一幕正式结束，第二幕重新回到奥布里视角。

## 二、周五狩猎决定

变量：

```text
huntDecision = 0 / 1 / 2
0 = 未决定
1 = 继续狩猎
2 = 取消狩猎
```

`dy_d5_hunt_decision` 不是日常三选一，而是第五天夜晚结束前的固定大事件决定。

继续狩猎：

- 周六狩猎通知存在。
- 周六骑装送达。
- 周日进入狩猎篇。
- 第八章结束后解锁西比拉骑装。

取消狩猎：

- 周六狩猎通知不存在。
- 骑装不解锁。
- 周日恢复普通休息日。
- 午后运行祭拜日固定事件。
- `普里森堡_声誉` -3 暂定。

## 三、狩猎说明页

说明必须同时表达三件事：

1. 狩猎是第一幕大型事件。
2. 进入以后主要使用西比拉视角，无法改变主要剧情走向。
3. 预计阅读时间约 60～90 分钟，特殊插图较多。

说明页的“返回游戏”只关闭说明页，不改变已经做出的“继续狩猎”决定。

## 四、狩猎篇选择数量

第四章：0 个主动选择。

第五章：0 个主动选择。

第六章：1 个主动选择，放在 `h6_reproach`。

第七章：1 个主动选择，放在 `h7_answer`。

第八章：1 个主动选择，放在 `h8_end`。

总数：3 个主要剧情选择。

其余原有选择全部删除或线性化，以保证连续文本和插图的铺垫。

## 五、狩猎篇视角

- 第四～第八章全部西比拉 POV。
- 不插 POV 横幅。
- 不在第八章结束瞬间切回奥布里。
- 第九章继续西比拉 POV。
- 第二幕开始时再切回奥布里 POV。

## 六、骑装系统

日常服装状态继续使用：

```text
x=0 → 女仆服
x=1 → 常服
```

狩猎骑装不进入 x 的轮换。

狩猎开始时只做：

```text
huntOutfit = riding
```

狩猎篇结束后可以解锁骑装并恢复日常服装系统。

## 七、第五、六天洗衣

- 每天普通衣物仍在午饭后处理。
- `x=0` 时当前为女仆服，洗后换常服。
- `x=1` 时当前为常服，洗后换女仆服。
- 非雨天：换下当天洗的衣服按次日可用处理。
- 雨天：当天不做衣服轮换，继续穿当前衣物。
- 连续下雨天数可用单独 `rainCnt` 记录；连续三天时暂定 `西比拉_健康 -1`、`西比拉_埋怨 +1`，只触发一次。
- 周六额外洗教师服，为周日后的后续课程周期做准备。

## 八、固定事件原则

固定事件：

- 周一～周六早晨：伊莎贝尔的课。
- 每天中午：全府午饭。
- 每天午饭后：洗衣。
- 周日午后：祭拜日固定事件，除非被大事件覆盖。

随机活动才使用白天剩余选择位。
