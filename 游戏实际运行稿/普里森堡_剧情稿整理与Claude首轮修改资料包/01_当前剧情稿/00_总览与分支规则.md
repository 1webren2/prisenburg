# 普里森堡第一幕剧情总览与首轮规则

## 1. 资料用途与优先级

这是一份交给 Claude Code 的首轮回填资料包。它同时含连续剧情审阅稿、按原节点 ID 展开的人工编辑稿和原著只读参考。各稿用途不同，不能仅凭文件名或篇幅判定互相覆盖。

**冲突处理优先级：**
1. 作者在对话中明确确认的规则与作者亲自写出的正文（尤其《第五天_狩猎取消线_作者原文只读.md》）。
2. 《第三至第六天_正式剧情稿_v2_人物性格与日程校正版.md》里的时间线、人物排程、分支和 POV 规则；如果与作者随后追加的专属分支正文冲突，以作者明确补充为准，并在报告中说明所需路由改动。
3. 各日“人工编辑稿”里的节点 ID、原有节点全文、选项、旗标和定位信息，用于映射运行文件。
4. 《第二天_玩法调整稿_v2》作为第二天选择/状态设计依据；《第二天_执行顺序明确版人工编辑稿》作为节点映射依据。
5. 原著参考文件只用来核对原文，不得润色、删节或改写原著文字。

历史重编版、短版和重复命名的旧版不收入本轮主资料包，以免 Claude 把多份互相冲突的版本当成同时生效的要求。

## 2. 时间线和分支

- 第一天周一：西比拉抵达普里森堡，第一夜；本轮仅供前情参考。
- 第二天周二：奥布里视角的第一天完整日常循环；课堂作为世界内固定事件照常发生，奥布里是否亲历由玩家选择决定。
- 第三天周三、第四天周四：奥布里观察视角；西比拉的私密感受主要进入她自己的日记，不由奥布里旁白直接宣称。
- 第五天周五：白天照常生活与准备；周日狩猎只允许出现一次正式世界决定。按作者最新明确规则，取消狩猎专属正文只在取消路线出现，不能在共用节点先播放一遍，再进入取消路线重复决定。取消分支的实际决定由作者原文中“后日的狩猎，取消了罢”呈现。继续狩猎路线必须使用不同的对应后续，不得播放取消段。
- 第六天周六，狩猎继续：白天维持奥布里日常；夜间由布朗通知西比拉并交付已提前准备好的骑装，只有这时临时切换西比拉视角，作为周日长篇特殊事件的入口。
- 第六天周六，狩猎取消：全天保持奥布里视角。不得通知西比拉狩猎、不得把骑装交付给她、不得切换到她的视角。伊莎贝尔在周六得知取消后表现出符合七岁孩子的失望。周六夜间亨利与奥布里的冲突由作者亲自写；保留空位/结构，不得代写对白、动作或冲突正文。已确认的后果是奥布里跌倒并被火盆烫伤脚。
- 第七天周日，狩猎继续：进入连贯的狩猎篇，主要采用西比拉视角，不要频繁切换 POV。入口应告知玩家这是较长的特殊事件，主线方向由周五决定，局部反应仍可能有选择。
- 第七天周日，狩猎取消：不能进入狩猎篇。普通周日休息/午后祭拜安排被奥布里受伤后的照料事件覆盖；奥布里无法起身，布朗忙于应对贵族，西比拉被请来照料。不要让狩猎取消线仍出现狩猎专属人物互动或猎场事实。
- 第八天周一：狩猎线进入《第九章》既定开场；取消线先用奥布里视角承接受伤状态，并通过伊莎贝尔询问西比拉为何称呼他“沃大人”的场景带出对话，再在不破坏 POV 与因果的前提下汇合到原著第九章。若现有素材不足以确定确切汇合节点，先报告，不擅自改动原著段落。

## 3. 不变规则

1. 同一时段中，每个关键人物在世界里只有一个实际地点/事件。可供玩家选择的场景可以是替代访问入口，但必须是互斥路线，不能把同一个人同时写在两个地点。
2. 没有被玩家访问的固定事件仍在世界内发生；但奥布里不能把未目击的细节当作亲眼所见，也不能拿到只属于亲历的反应/奖励。必要时通过正确角色在对话中讲述或在日记中补完。
3. 玩家视角以奥布里为主。奥布里不能直接说出西比拉未表达的内心感受。私密心理由西比拉日记承载。
4. 人物性格要连续：西比拉有尊严、纪律和主见，不是单纯顺从；伊莎贝尔仍是七岁孩子，不能一夜变得听话；海尔要有真实的行动与关系；布朗既是管家也与奥布里熟悉，允许有机的玩笑和分寸。
5. 选择不提前显示数字效果或心理后果。选择的意义通过人物反应、后续对话和日记回响体现。
6. 不新增与现有旗标重复的机制。先检查已有状态、效果、默认结算、快照与测试，再决定实现方式。
7. 原著正文和作者原句不得润色。不能因为游戏化就删除、压缩或改变既有小说文本；如必须更改路线或停用旧入口，优先改路由/触发，不改原文内容。
8. 不删除或重命名独有原图。狩猎图和既有背景应先检查是否可复用；本轮不创作新图、音频或资产系统。
9. `stage0/` 一律不动。不得顺手重构 Electron、C++、UI、保存格式或 `CLAUDE.md`。
10. `13_幕间自由活动.md` 是独立侧厅层，其中占位文案和 `freeRoam` 锚点有特殊规则；除非修复主线必然涉及，否则本轮不改它。

## 4. 需要首轮重点找出的冲突

- 旧 `07_第六天.md` 中 `c1_door` 到 `c27_end` 的实际时序/触发，与新的“周五做决定、周六白天保持奥布里日常、只在周六夜间（继续线）通知西比拉”存在冲突。原文必须保留，但旧入口不能与新安排重复触发。
- 取消线专属作者原文与较早稿中“共用节点里作正式决定”的设计可能造成重复选择/重复通知。以本资料包的最新分支规则为准。
- 取消线“明天衣服赶制完成”只是一句账册/工作信息，不意味着取消狩猎分支仍向西比拉送骑装。
- 作者原文中布朗称海尔为“女儿”并使用“她”与其他设定可能不一致；首轮只报告疑点，禁止改原文。
- 周六夜晚亨利冲突正文由作者写，Claude 不得代写。可以搭建到该场景前后的路由，但不能填充该场景正文。
