# Stage 0 · 日常模式实验原型

**这是临时的。** 它只回答一个问题：

> 「安排一天、插手西比拉的日程、看人物怎么反应」这件事，
> 作为一个**游戏**（而不是作为小说）开始好玩了吗？

如果不好玩，后面那个 Scheduler 就不用做了。所以这里**不预实现任何后续系统**。

---

## 怎么跑

```
node server.js
```
然后开 http://localhost:3000/stage0/

`server.js` 本来就是 `express.static(仓库根目录)`，所以 `/stage0/` 不用改服务器。

命令行走查（不开浏览器，会打印每一天的数值进出）：

```
node stage0/walkthrough.cjs
```

## 这里面装了什么

一个**「正式日常模式开始之后的第一天」**：从奥布里房间醒来 → 今日安排 → 早晨 / 中午 /
午后 / 夜晚四个时段，每个时段去一个地方、遇上一个人、做一件事，每件事做完回到 Hub。

序章（马车 → 普里森堡 → 大厅初见）**不在**这里，它仍然是 `act1/` `act2/` `act3/`
里那份一个字都没改过的正式剧本。

四个时段**各有三个可去场景**，右下角点图标进去：

| 时段 | 可去 | 她在做什么 | 玩家能动手的地方 |
|---|---|---|---|
| 早晨 | 教室 / 大厅 / 外院 | 给伊莎贝尔上礼仪课 | 站她这边，或者把课停掉 |
| 中午 | 书房 / 后坡 / 外庭院 | 手上没有非做不可的事 | 叫她出来走走（占的是她自己的时间）、或者叫她来打一场 |
| 午后 | 洗衣房 / 外院 / 马厩 | 在一楼洗衣房做工 | 让她别洗了，换成别人 |
| 夜晚 | 她的房间 / 账房 / 伊莎贝尔的房间 / 回房睡下 | 在房里备明天的课 | 打断她，陪玩家说话 |

**决斗固定在【中午】发起**（设计如此，不是引擎限制）。

场景菜单是右下角那排图标按钮：不带编号，鼠标悬停会浮出场景名（往左弹，不压画面右半边），
菜单正上方有一行时段小字（「早晨 · 选择去向」）—— 选项一亮出来对话框就收起来了，
这行字是补回「现在几点」的。
**「后坡 · 散步」原来是折在书房里的二级选项，优先级 2 把它提回了中午的顶层菜单** ——
那是「她中午通常无事，所以可以把她的时间占掉」这个设计点。

**一天的最后是日记本。** 夜晚过完回到自己房间，你把她叫来，交代从今往后每天
记一份府里的事送来（`d1_diary_intro`）；她应下、退下，十几分钟后门又被敲响 ——
**就在这一句之后**，那本册子摊开了。不是弹窗，是一本缓缓打开的书，**一页纸**，
从上往下一顺读：书名 → 日期和天气 → 今天做过的事 → 一条分隔线 → 她写的那一页。
合上就结束这一天。

分隔线以上是**按记录旗现算的**（停没停课、去没去洗衣房、打断没打断备课、
打没打过），所以它是这一天的显性存档。线以下不随玩家的操作变 —— 那是
**她选择让你看到的内容**，不是系统显示的数值。详见 `日记系统设计.md`。

左上角全天挂着一行「第 X 天 · 早晨」（天数先占位），位置来自你此刻在哪个时段。

**第二天起**日记的入口才是 HUD 上的【日记】按钮 —— 第一天是剧情替玩家翻开的。
Stage 0 只有一天，所以那颗按钮**属于 Stage 1，这里不做**（设计稿 §5.2）。

**每个动作都同时给出好结果和坏结果。** 这不是 bug，是 Stage 0 最想让你看到的东西：

- 把课停掉 → 好感 ↑↑，埋怨 ↑↑，伊莎贝尔的礼仪进度 ↓
- 让她别洗衣 → 好感 ↑，埋怨 ↑，**府里的声誉 ↓**
- 打断备课 → 好感 ↑，埋怨 ↑↑↑，伊莎贝尔明天的课少一点
- 站她这边把课上完 → 好感 ↑，尊敬 ↑，**伊莎贝尔对玩家 ↓**

## 看得见的 / 看不见的

侧栏和结局屏上**只有六个**：西比拉好感 / 健康 / 埋怨、伊莎贝尔礼仪成长、
普里森堡秩序 / 声誉。

这些**一个都不显示**，但一直在记账：
西比拉反抗 / 恨意 / 亲密 / 尊敬、仆人尊敬、海尔好感、伊莎贝尔好感、
以及当天的记录旗（今天停没停课、去没去洗衣房、打没打断备课、决斗打了几场）。

隐藏值不进 `config.statOrder`，所以侧栏和结局屏都渲染不出来——
`walkthrough.cjs` 里有一道核对专门盯着这件事。

## 什么都没碰

下面这些文件**一个字节都没改**，Stage 0 是挂在它们旁边的：

```
act1/engine.js        act1/ui.js         act1/style.css
act1/index.html       act1/story.json    act2/story.json    act3/story.json
server.js             tests/（全部）
images/               各幕 source/
```

`stage0/index.html` 直接 `<script src="../act1/engine.js">` + `../act1/ui.js`，
连 `mount()` 要的那些元素 id 都是照 `act1/index.html` 抄的。
`ui.js` 在浏览器里 fetch 的是**同目录**的 `story.json`，所以这个页面读的是
`stage0/story.json`，没有动到第一幕。

没有新增 Scheduler，没有 `scheduler.js`，没有多 NPC 自主模拟，
没有复杂时间系统，没有经济系统，没有结局系统，没有加新属性。

## 已知的、留给下一阶段决定的事

1. **决斗只在【中午】** —— 这是设计决定（决斗固定在正午发起），不是引擎限制。
   反过来说，引擎的 `next` 是写死的，没有「回到来的地方」这种动态返回点，
   真要改成全天任意时段可发起，得复制整条链或者动引擎。
2. **选项闸门是灰按钮，不是消失**。引擎的 `availableChoices()` 会返回被 `if` 挡住的选项
   （`enabled:false`），界面画成 `🔒 …`。Stage 0 靠 `lockedHint` 写得像有意为之。
   要做到「这个时段这里没人」那种干净菜单，得给引擎加过滤开关。
3. **结局屏只有绝对值，没有今日增量**。`snapshot()` 只存绝对值，引擎没有 diff 接口。
   Stage 0 是用 `d1_end` 里几句按记录旗拼出来的叙述来代替结算屏的。
4. **数值下界会吃掉负增长**。`伊莎贝尔_礼仪成长` 起点是 0 的时候，
   「进度倒退」在数值上永远看不见（被 `[0,100]` 的下界夹住）。
   现在起点给到 3。正式做的时候，这类「会被下界吃掉的成长值」得统一处理。
5. **马厩 / 账房 / 伊莎贝尔的房间是桩**，台词只有两行、开头标着〔占位〕，
   各给了一个 ±1 的数值让按钮不是死的。**这是为了量「三个选项比两个、一个好玩吗」，
   不是为了写内容** —— 内容等验收通过、进 Stage 1 再写。
   同样地，这三个地方没有专门的背景图，各借了别的图顶着（`bg_stable` / `bg_office` /
   `bg_isabelle_room`，剧本里每个都标了，有图只改那一行 `src`）。
6. **日记只有一天一页**。多天、翻页、结算屏上的回看入口、HUD 上那颗【日记】按钮，
   都是 Stage 1 的事。日记的内容分档（四档）也只在 `日记系统设计.md` 附录 A 里躺着，
   一行都没实现 —— Stage 0 只有一天，现在定阈值等于拍脑袋。
7. **关书之后 `d1_end` 的日终旁白在浏览器里被跳过了**（终端里照常演）。
   因为那几句说的正是日记上刚记过的事，玩家刚在书上读过一遍。
   要让浏览器里也演，把 `stage0.js` 里 `closeDiary()` 那个循环去掉即可。
8. **「日记摊开的时机」在走查里只看得到一半**。那条规矩是「最后一句播完之后」，
   浏览器里靠 `stage0.js` 拦下那一下输入实现（捕获阶段的 keydown / 点对话框），
   走查跑的是 ui 层、看不见它。所以走查核的是它依赖的那个纯函数
   （`diary.js` 的 `atLastLine()`，配一句 `00001` 的边距），拦输入那一层只有人眼。

## 文件

| 文件 | 是什么 |
|---|---|
| `index.html` | 页面骨架（照抄 `act1/index.html`，路径改指 `../act1/` 和 `../images/`） |
| `stage0.css` | Stage 0 专用覆盖层（排在 `../act1/style.css` 后面加载）：对话框上沿那条暗带 + 右下角场景菜单 + 左上角时间显示 + 日记本 |
| `stage0.js` | Stage 0 专用渲染层（排在 `../act1/ui.js` 后面加载）：时段菜单画成图标按钮、左上角挂时间显示，在 `d1_diary_intro` 最后一句播完之后把日记本摊开 |
| `diary.js` | 日记的**规则**（纯逻辑，不碰 DOM）：取哪天、记哪几条、句子播完了没有。`stage0.js` 和 `walkthrough.cjs` 共用这一份 |
| `story.json` | Stage 0 的实验剧本，38 个节点，全部 `pov: 奥布里`；顶层另有 `diary` 数据块（只剩书名、日期、天气） |
| `walkthrough.cjs` | 无头试玩走查：六条路线 + 日记本 + 原文核对 + 隐藏值不露脸 |
| `日记系统设计.md` | 日记系统的设计稿（**v3.1 定稿**）。代码按 §12 那张表改过了，两边现在对得上 |
| `README.md` | 就是你正在看的这份 |
