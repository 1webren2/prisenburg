## 三、原作者是谁、怎么对账

拿不准某句台词是不是原文的时候：

```bash
node tests/run.cjs fidelity     # 只看原文核对这一道
node tests/fidelity.cjs         # 同上（单独跑）
```

它做两件事：

- **正着查 —— 不许自己编**：把剧本每一句切成小句，逐个到原文里找，找不到就是杜撰。
- **反着查 —— 不许漏掉**：把原文每一句切成小句，逐个到剧本里找，找不到就是丢弃。

**说话人归属单独查**（引号里的内容算谁说的），只在「紧挨着引号的地方」出现人名 + 说话动词时才判定。

唯一的例外：自由活动里的 `[...]` 占位文本是用户明确允许的，
所以它们放在 `freeRoam` 数据块里、**不进节点的 `dialogues`** —— 进了就会被拦下。
