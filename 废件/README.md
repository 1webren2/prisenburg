# 废件

按你的要求，把仓库根上「不知道还有没有用」的东西全收在这儿了。**只是搬过来，一样没删。**
下面逐条写清是什么、删了能不能捞回来、我建议怎么办 —— 你划完再动手。

**「能恢复吗」怎么读：**

- **能从 git 捞回** = 文件在 git 里跟踪着，删了之后 `git show <旧提交>:<路径>` 还能拿出来。
- **删了就没了** = 被 `.gitignore` 挡住了，git 不管它 —— **这类是最该先确认的**。

   `重复文件/`、`空目录_测试/`、`server.log`。
